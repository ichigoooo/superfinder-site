更新日志。

从 1.0 到现在，每个版本做了什么。官网当前版本 1.7.1（build 14）。

1.7.12026-10-21当前版本
  • 新增 摇晃唤出暂存架：从访达拖起文件后，快速左右摇晃指针——当 SuperFinder 不在前台时，菜单栏图标下方会自动弹出暂存架，空架显示「拖入此处暂存」，有内容则列出已有条目，边缘亮起表示可以放下。
  • 新增 不必先把文件挪回 SuperFinder：摇晃即唤出，容器会一直等你投放；放到别处或按 Esc 会自动收起。
  • 优化 只认文件拖拽：拖动窗口、选择文字或上下乱晃都不会误弹出；同一场拖拽短时间内不会反复弹出。
  • 优化 不抢焦点：容器出现、收起都不打断 Finder 或你正在拖的文件，拖拽全程不中断。
1.7.02026-10-20
  • 新增 收藏项可设「显示名」：右键任一收藏项选「设置显示名」，只改收藏栏里显示的名字，改过的名字加粗显示，鼠标悬停仍显示完整路径；把输入框清空即恢复默认名。
  • 修复 拖到暂存架放不进去：文件拖进暂存架容器内即可松手放入，此前只有拖到暂存架图标附近才生效，过程中还会忽亮忽灭（应用内与菜单栏托盘同症）。
  • 修复 拆分后点上面板不落焦：标签内拆成上下两个面板后，点上面板焦点不再留在下面板，接着点收藏栏也会跳到你点的那个面板。
1.6.02026-10-17
  • 新增 标签组：右键任一标签选「添加到新组」，把相关的一排标签收进一个带颜色的组，窗口再满也不乱。
  • 新增 折叠与展开：点组名即把整组收成一个小色点，再点展开；点开组内任一标签时组会自动展开。
  • 新增 拖拽整理成员：标签可拖进组、拖出组、在组间移动，组内顺序随手排；拖走组里最后一个成员时组自动解散。
  • 新增 组可重命名与换色：右键组名改名，或在 8 种颜色里换一个。
  • 新增 标签组随会话保存：退出再打开，组和成员照原样回来。
  • 新增 保存标签组到收藏栏：右键组名选「保存标签组」，收藏栏与起始页出现组书签，单击一键打开整组，⌘点击或中键后台打开。
  • 新增 文件夹「打开全部标签页」：右键收藏栏的文件夹书签，把里面的子目录一口气开成一排标签。
  • 优化 组成员下方以连续色条标出范围，一眼看清谁在同一组。
1.5.12026-10-14
  • 新增 收藏栏书签可右键：文件夹和文件都能在书签上点右键，直接打开、移出收藏夹或重命名。
  • 新增 收藏组里的书签也能右键：先展开收藏组，再对里面的单个书签点右键，菜单动作与外层一致。
  • 修复 收藏组内右键书签曾直接跳转到该书签；现在只弹菜单，不会误打开。
  • 修复 右键按下与松开之间可能误激活菜单项的问题：菜单在松开鼠标后才出现。
  • 优化 书签已失效时菜单项自动置灰：文件夹的「打开」和文件的「在访达中显示」不可用，但「重命名」与「移出收藏夹」始终保留，失效书签仍可清理。
1.5.02026-10-14
  • 新增 详细列表加行号：每行左侧标出行号，排序后行号跟着重排。
  • 新增 列与列之间有细分隔线；当前排序列整列加重并标出排序方向。
  • 新增 拖到菜单栏图标上暂存：把文件拖到图标上会弹出暂存容器，松手即暂存，不打断你在访达里的操作。
  • 新增 菜单栏图标数量角标：主窗口收起而暂存架有内容时显示数量（超过 9 显示 9+）；重新打开窗口后暂存内容自动回到窗内。
  • 新增 首次启动自动预置常用收藏：主目录、桌面、文稿、下载、应用程序直接出现在收藏栏。
  • 新增 起始页建议可单条删除：右键建议项选「从建议中删除」，磁盘上已不存在的目录会自动清理。
  • 优化 全窗口控件统一为新样式：按钮、输入框、弹窗一致；文件简介窗与信息区改卡片式排版，状态栏改为等宽数字读数。
  • 修复 首次打开应用显示空白页，现在直接进入主目录。
  • 修复 收藏栏书签中键点击改为后台新标签打开，不再覆盖当前窗口。
  • 修复 关闭最后一个标签页后再新建标签（⌘T 或点 +）导致崩溃。
  • 修复 关掉最后一个标签后唤回窗口，仍显示已关闭的标签、地址栏回车无反应。
1.4.22026-10-11
  • 新增 关窗不再退出：点窗口红叉只收起窗口，app 留在后台——用快捷键、菜单栏图标或点 Dock 图标随时唤回（⌘Q 仍是退出）。
  • 新增 菜单栏图标：左键显示或收起窗口，右键可直接进快捷键设置、系统设置与退出。
  • 新增 存量 ⌥Space 一次性提示：启动时询问是否改为 ⌥⇧Space，作答后不再出现。
  • 修复 行内重命名时偶发出现空心框、字迹透出的显示问题。
  • 修复 深色模式下行内重命名输入框底色发黑。
1.4.12026-10-11
  • 新增 收藏栏收藏文件：右键菜单或拖拽把文件加入收藏栏，单击用默认应用直接打开。
  • 新增 连接服务器：⌘K 挂载 SMB 共享并新开标签进入，地址栏支持直接输入 smb:// 地址，自动记住最近连接的服务器。
1.4.02026-10-10
  • 新增 在新标签页打开：文件夹右键「在新标签页中打开」，文件与书签条目支持中键在后台打开，不打断当前位置。
  • 修复 拖拽时拖影偶发从窗口顶部飞入。
  • 修复 拖拽悬停在文件夹自身上会误触发弹簧展开；悬停确认增加 0.8 秒下限，防误触。
  • 修复 免费版徽标文字重叠的显示问题。
1.3.02026-10-08
  • 新增 内置图片工具第三批：裁剪到比例、压缩到目标体积、清除元数据（含 GPS 隐私）、透明背景填充、方向归一化。
  • 新增 批量重命名支持按拍摄时间重命名，读取照片 EXIF 拍摄时间。
  • 新增 收藏栏书签拖拽排序。
  • 新增 Pro 解锁：插件端口 ¥38 一次性买断，离线验签，无需账户。
  • 修复 图片旋转方向（右旋/左旋相反）与部分照片方向烘焙错误的两处方向问题。
  • 修复 首次访问桌面、文稿、下载等目录时权限弹窗缺少用途说明。
  • 改进 工具执行失败时，提示与进度卡现在显示具体原因。
1.2.02026-10-06
  • 新增 侧边栏工具区：按文件类型给出处理工具，四域十一件——图片（转格式/调整尺寸/旋转翻转/抠图）、PDF（合并/压缩/提取页面）、音视频（转码/提取音轨）、文本（编码转换/JSON 格式化）。
  • 新增 外部插件端口：导入 .sfplugin 插件即接入侧边栏工具区，写动作照常可预览、可撤销（官网版独有）。
  • 修复 画廊模式预览 PDF 时滚轮无响应、拖拽卡顿——预览改用进程内渲染（PDF、文本、图片原生呈现，QuickLook 兜底）。
  • 修复 画廊点开大图会把窗口撑大的问题。
  • 修复 地址栏点入编辑态后内容显示空白；图标视图选中后按空格预览不弹出；画廊预览区只显示窄条。
1.1.02026-10-02
  • 新增 置顶：常用文件钉在目录顶部，拖动排序。
  • 新增 批量重命名：查找替换、正则、序号、大小写转换，实时预览，整批撤销。
  • 新增 显示简介与系统服务集成；一键显示隐藏文件。
  • 新增 底部地点栏：iCloud、AirDrop、磁盘与废纸篓快速可达，清空废纸篓带确认。
  • 改进 更多访达快捷键贯通标签、窗格与列表；地址栏支持中文输入法全角字符；最近关闭标签在起始页成列。
  • 修复 图标与画廊视图的单击选中与高亮；大目录浏览的刷新风暴、闪烁与选中漂移；清空废纸篓菜单无响应；废纸篓未授权时改为引导开启「完全磁盘访问」。
1.0.02026-10-02
  • 首发 浏览器式文件工作台：地址栏直达（粘贴回车 + Tab 逐层补全）、标签页与四向窗格拆分、命名布局保存、引用式暂存架、搜索即地点、四视图 + Quick Look、会话还原、写动作 ⌘Z 可撤销、删除恒进废纸篓。
