Everything's here.

⌘Q and the tab groups, the four-way pane trees, the shelf references — all of it saved. Reopen, and the scene is exactly as you left it. Real browsers restore sessions. So does this.

Whole trees come back

Not just tabs: each pane tree's structure, ratios, and every folder it held — restored together.

Crashes count too

Snapshots land on disk continuously, throttled. A crash gets the same treatment as a clean quit.

See everything.
Open nothing.

Detailed list, hierarchy outline, icon grid, gallery with filmstrip — the same files at four densities, ⌘1–⌘4 switching between them. Space brings up the system Quick Look. The window up top switches too.

Gallery & filmstrip

Big image up top, a filmstrip pinned to the bottom, three-way sync. The selection ring is the signature deep outline — not system blue.

View options, ⌘J

Icon size in four steps, grid spacing, label position, filmstrip size, sort — a floating panel trimmed to the current view. Set it once, it sticks everywhere.

Fast, but never out of bounds.

What got browser-ified is the operating, not the boundaries.

Trash is the only exit no permanent delete

Deletion always goes to the system Trash. There is no path around it inside the app. Not a default — an invariant.

No account. No cloud. No telemetry.

No networking code, no analytics, no “anonymous usage statistics.” Your files never leave your Mac — and neither does this site (zero third-party requests).

Every write action undoes full audit trail

Moves, copies, renames take effect immediately; ⌘Z reverts silently — and every write lands in an auditable ledger. That ledger is watched by 1,458 unit tests; every number drills down to the file it comes from.
