SuperFinder 与访达：文件管理器逐项对照。

一台面向重度文件操作的 macOS 文件管理器，与系统自带的访达 Finder 对照如下：

能力访达 FinderSuperFinder
地址栏直达⇧⌘G 对话框粘贴路径常驻地址栏：粘贴回车直达，Tab 逐层补全
标签页有有，另含命名布局保存与新标签还原
窗格对照无（需开多个窗口）标签内四向拆分，比例与布局可保存
暂存整理无（靠桌面或文件夹倒手）引用式暂存架：拖入只记引用，拖出才移动
批量重命名有（简单规则）实时预览 + 查找替换 + 整批撤销
会话还原重启可恢复窗口标签、窗格、暂存架与所在目录整现场还原
扩展能力自动操作 / 快速操作不装第三方扩展，能力全部内置
写操作撤销⌘Z 有限移动 / 复制 / 重命名全可撤销
删除纪律废纸篓 + 右键立即删除恒废纸篓，无永久删除入口
