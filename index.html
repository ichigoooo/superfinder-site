常见问题。

SuperFinder 是免费的吗？

是。App Store 版与官网直发版均免费下载；官网版另含外部插件端口，可用 Pro 密钥（¥38 一次性买断）解锁，官网购买通道建设中。

文件会被上传到云端吗？

不会。SuperFinder 自身零网络：无账号、无云同步、无遥测，文件不出本机。外部插件是用户自装的代码，其网络行为归用户。

需要什么系统？

SuperFinder 需要 macOS 14 或更高版本，界面提供简体中文与 English 两种语言。当前版本 1.6.0（build 12，2026-10-17 发布），安装即用，无需账户或额外配置。

它和访达（Finder）是什么关系？

SuperFinder 可作为日常浏览的主力文件管理器：地址栏直达、标签与窗格对照、暂存架与会话还原；它与访达的标记、QuickLook、权限等系统机制互通，无需删除或替换访达。

官网版和 App Store 版有什么区别？

官网直发版含外部插件端口（可加载自定义 .sfplugin 插件），App Store 沙盒版受沙盒限制不含此能力；其余功能一致，官网 DMG 经 Developer ID 签名与 Apple 公证。

下载安全吗？

安全。官网 DMG 使用 Developer ID 签名、经 Apple 公证并装订票证，页面提供 SHA-256 校验和可自行核验；App Store 版经苹果审核上架。

卸载干净吗？

干净。SuperFinder 是单个 .app，拖入 /Applications 即用，无后台守护进程；删除 .app 即完成卸载。登录项为可选功能，若开启过，在系统设置的登录项列表里移除即可。

1.6.02026-10-17当前版本
  • 新增 标签组：右键任一标签选「添加到新组」，把相关的一排标签收进一个带颜色的组，窗口再满也不乱。
  • 新增 折叠与展开：点组名即把整组收成一个小色点，再点展开；点开组内任一标签时组会自动展开。
  • 新增 拖拽整理成员：标签可拖进组、拖出组、在组间移动，组内顺序随手排；拖走组里最后一个成员时组自动解散。

  • 新增 标签组随会话保存：退出再打开，组和成员照原样回来。
  • 新增 保存标签组到收藏栏：右键组名选「保存标签组」，收藏栏与起始页出现组书签，单击一键打开整组，⌘点击或中键后台打开。
  • 新增 文件夹「打开全部标签页」：右键收藏栏的文件夹书签，把里面的子目录一口气开成一排标签。
  • 优化 组成员下方以连续色条标出范围，一眼看清谁在同一组。
