访达学会了标签页，
然后停在了那里。

SuperFinder 把剩下的整套补完：地址栏直达、搜索即地点、书签栏分层、起始页与最近关闭。会 Chrome / Safari 就会 SuperFinder——二十年的浏览器肌肉记忆，原样复用。

⌘L地址栏 ⌘T新标签 ⌘F搜索

地址栏三件事

粘贴路径回车直达——从终端或 AI 输出里复制来的那种；输入 ~ 再按 Tab 逐层补全；一键复制当前路径。首屏的窗口里就能试。

搜索即地点

搜索结果不是一次性页面——可后退、可书签、可还原。文件夹和搜索结果在这里是同一种东西：地点（Place）。

书签栏与起始页

书签按文件夹分层、附图标，常用位置放多少都排得开；⌘T 是 Safari 式起始页，最近关闭的标签整棵恢复。

关掉。回来。
一切还在。

⌘Q 退出，标签组、四向拆好的窗格、暂存架里的引用，全部落盘。重开，原样回来。真浏览器都恢复会话——丢标签组的「浏览器」不合格。

整树还原

不只恢复标签：每棵窗格树的结构、比例、各自所在的文件夹一起回来。

崩溃也算数

不是「正常退出才保存」——快照带节流持续落盘，崩溃后与手动退出同等待遇。

拆出来的现场，
收得回来。

重度文件操作的高频动作是「对照」。SuperFinder 的对照发生在标签内部——四向递归拆分、抓手换位；拆好的现场还能命名收藏，新标签一键还原同一布局。双栏管理器回答「怎么同时看两个目录」，回答不了「你的工作现场如何被保存」。

标签内递归拆分

右键空白处四向拆分，想拆多深拆多深；窗格边缘抓手拖动即原位换位。窗口级恒单窗格——一个窗口就是一台浏览器。

布局收藏

地址栏 ▦ 钮把拆分结构、各窗格目录、视图模式一并命名保存；收藏栏点击，新标签原样还原同一现场。

暂存架

跨标签搬运的中转托盘——拖入只记引用，原文件不动；跟随会话，重开还在；拖出那一刻才发生唯一一次移动。

选中，就地处理。

侧边栏上半是精简信息——大预览、名称、种类、标记；向下滚动进入工具区：按所选文件的类型出现对应工具，参数、预览、确认、撤销一条龙。

四域十一件内置工具

图片（转换格式 / 调整尺寸 / 旋转翻转 / 抠图）· PDF（合并 / 压缩 / 提页）· 音视频（转码 / 提音轨）· 文本（编码转换 / JSON 格式化）。

产物也走未决引擎

工具不是旁路——每个产物的落盘都是预览 → 确认 → ⌘Z 可撤销；撞名自动让位，原件只有引擎碰。

首屏可玩

在上面的窗口选中两张照片 → Convert Format → Preview → Confirm → ⌘Z，全程真实可操作。演示数据，判定逻辑与应用一致。

Convert Format PNG · JPEG · HEIC

格式分段、EXIF 开关、产物名（改名只认词干，扩展名恒随所选格式）、目标目录——每一步都是应用里的那一步。

Resize 16–10000 px

宽高联动带比例锁，默认产物名随宽度段派生；多选时逐文件派生，互不覆盖。

Preview → Confirm

操作清单 from → to 逐行可读；确认走既有进度与音效，⌘Z 整批撤回——与移动、复制、重命名同一条通道。

工作台，
给你留了位置。

.sfplugin 单文件插件：manifest 声明 + 任意技术栈的入口脚本——bash、Python、Node 都行。设置窗导入，即挂进侧边栏工具区。

两种模式，都过引擎

plan 吐操作表（白名单：rename / move / mkdir），transform 吐暂存产物——落盘唯一通道都是未决引擎：预览 → 确认 → 可撤销。

子进程 + 账本

插件在独立进程组运行，stdin/stdout JSON 契约；输出上限、超时梯子、越权拒绝、孤儿暂存清扫，全部内建。

官方开发 Skill

设置窗一键导出——manifest 规范、契约文档、双示例插件（bash / Python）、独立校验器。让 AI agent 也能替你写插件。

边界诚实

插件是你自装的代码：网络行为不设限，责任归你。app 自身代码不含网络功能——这是事实陈述，不是设置项。

快，但不越界。

浏览器化的是操作，不是边界。

废纸篓是唯一出口 无永久删除入口

删除恒走系统废纸篓，应用内不存在绕过它的路径。不是默认设置，是写死的不变量。
