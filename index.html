访达学会了标签页，
然后停在了那里。

SuperFinder 把整套补齐：地址栏直达、搜索即地点、书签栏分层、起始页。会 Chrome 就会它，二十年的习惯直接搬过来。

⌘L地址栏 ⌘T新标签 ⌘F搜索

地址栏三件事

粘贴路径回车直达，终端或 AI 输出里复制的那种；输入 ~ 按 Tab 逐层补全；一键复制当前路径。上面的窗口就能试。

搜索即地点

搜索结果可后退、可书签、可还原，和文件夹一样是地点（Place）。

书签栏与起始页

书签分文件夹、附图标，放多少都排得开；⌘T 起始页，最近关闭的标签整棵恢复。

关掉。回来。
一切还在。

⌘Q 退出，标签组、窗格、暂存架引用全部落盘。重开，原样回来。真浏览器都恢复会话。

整树还原

每棵窗格树的结构、比例、所在文件夹一起回来。

崩溃也算数

快照带节流持续落盘，崩溃和手动退出同等待遇。

拆出来的现场，
收得回来。

对照是重度文件操作的高频动作。这里的对照发生在标签内部：四向拆分、抓手换位，拆好的布局命名收藏，新标签一键还原。双栏管理器管的是同时看两个目录，这里存的是整个工作现场。

标签内递归拆分

右键空白四向拆分，想拆多深拆多深；抓手拖动即换位。窗口恒单窗格，一个窗口就是一台浏览器。

布局收藏

▦ 钮把拆分结构、各窗格目录、视图模式命名保存，收藏栏点击即在新标签还原。

暂存架

拖入只记引用，原文件不动；跟随会话，重开还在；拖出那一刻才移动文件。

选中，就地处理。

上半是信息：大预览、名称、种类、标记。往下是工具，按所选类型出现，参数、预览、确认、撤销都在里面。

四域十一件工具

图片：转换、缩放、旋转、抠图；PDF：合并、压缩、提页；音视频：转码、提音轨；文本：编码转换、JSON 格式化。

产物也走未决引擎

每个工具的落盘都经预览、确认、⌘Z 撤销，撞名自动让位，原件只有引擎碰。

首屏可玩

上面的窗口里选中两张照片，Convert Format、Preview、Confirm、⌘Z 全程可玩。演示数据，逻辑与应用一致。

Convert Format PNG · JPEG · HEIC

格式分段、EXIF 开关、目标目录；产物名只认词干，扩展名随格式。

Resize 16-10000 px

宽高联动带比例锁，产物名随宽度派生；多选时逐文件派生，互不覆盖。

Preview → Confirm

操作清单 from → to 逐行可读，确认后 ⌘Z 整批撤回，与移动、复制同一条通道。

工作台，
给你留了位置。

.sfplugin 单文件插件：manifest 加任意技术栈的入口脚本，bash、Python、Node 都行，设置窗导入即挂进侧边栏。

两种模式，都过引擎

plan 吐操作表（rename / move / mkdir 白名单），transform 吐暂存产物；落盘唯一通道都是未决引擎。

子进程 + 账本

独立进程组运行，stdin/stdout JSON 契约；输出上限、超时梯子、孤儿暂存清扫全部内建。

官方开发 Skill

设置窗一键导出 manifest 规范、契约文档、双示例插件和校验器，AI agent 也能替你写插件。

边界诚实

插件是你自装的代码，网络行为归你负责；app 自身代码不含网络功能。

快，但不越界。

浏览器化的是操作，不是边界。

废纸篓是唯一出口 无永久删除入口

删除恒走系统废纸篓，应用内没有绕过它的路径，也没有开关。

零账号 · 零云 · 零遥测

app 自身代码不含网络功能，无账号、无云、无统计上报；外部插件是用户自装代码，网络行为归用户。本站同样零第三方请求。
